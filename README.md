# Spark Quest

> **Duolingo 风格的 Apache Spark 学习应用（单机本地版）**
>
> 用游戏化的方式，把 Apache Spark 学牢、记牢、坚持学下去——不用报班、不用账号、数据全在本地。

Spark Quest 把「学新课 → 测验 → 间隔复习 → 连续打卡 → 收集徽章」串成一条**学习闭环**。
它不是一门视频课，而是一套你会天天回来刷的练习系统：每一课都有结构化讲解，学完立刻测验，
之后还会按节奏提醒你复习，防止学完就忘。

## 你能用它做什么

- 🗺️ **课程地图**：8 个阶段、66 课，一条蜿蜒向上的学习旅程。走过的路会被点亮，随时知道「我在哪、下一步学什么」。
- 📖 **课程学习**：每课用「人话理解 → 心智模型 → 比喻的边界 → 技术定义 → Spark 内部发生了什么 → 示例 → 易错点」七段式讲透，还有**我的笔记**随手记。
- ✅ **课后测验**：L1–L7 使用各课独立的 5 道课末检验题，L0 沿用原有抽样，≥80%（4/5）即判定掌握，并自动解锁下一课。
- 🔁 **间隔复习**：掌握后的课会按 `1 → 3 → 7 → 14 → 30 → 60 → 120 天` 的节奏提醒你回来复习，必须 5/5 全对才算过关，专治遗忘。
- 🔥 **连续学习（Streak）**：每天学一点就记一笔。连续天数不断就保持；隔了**一整天**没学才断（不是"漏一次就清零"）。
- 🏅 **徽章成就**：20 枚徽章等你收集——通关每个阶段、百题斩、完美术、连续学习、修复 bug、闪电战……其中 **2 枚是隐藏徽章**，达成前不会透露名字。
- 📊 **今日概览（Dashboard）**：一屏看总进度、今日推荐课、今日待复习、连续天数、最近解锁的徽章。

## 学习闭环是怎样的

```text
学一课 → 课后测验（≥80% 掌握）→ 解锁下一课
                  ↓
        进入间隔复习周期（防遗忘）
                  ↓
  到期复习 → 5/5 全对 → 间隔拉长一档
                  ↓ 没全对
         重读本课 → 立即再战 → 直到 5/5
```

> L1–L7 的课末检验与复习使用不同的五题组；L0 沿用原有题库抽样。门槛仍为学习 4/5、复习 5/5。

## 快速开始

### 第一次运行（克隆仓库后只需做一次）

```bash
# 后端：创建虚拟环境并装依赖
cd backend
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt

# 前端：安装 npm 依赖
cd ../frontend
npm install
```

### 日常启动（开两个终端）

```bash
# 终端 1：后端（端口 9000）
cd backend
.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 9000 --reload

# 终端 2：前端（端口 6001）
cd frontend
npm run dev
```

然后浏览器打开 **http://localhost:6001** 即可。

> **端口说明**：前端必须用 **6001**。曾经用过的 6000 被浏览器列为「不安全端口」会直接拒绝访问，
> 表现为页面打不开或报「网页似乎有问题或已永久移动」。后端用 9000，不在黑名单里。

数据库（`backend/spark_quest.db`，SQLite）会在**后端首次启动时自动建库并播种**，无需任何手动操作。

## 常见问题

- **页面打不开？** 确认前端跑在 `6001`、后端跑在 `9000`，且两个终端都没有报错退出。
- **我的学习记录存在哪？** 正式成绩、SRS、笔记等保存在 `backend/spark_quest.db`；互动作答、补救、隔天验证和毕业草稿另存于当前浏览器。复制数据库不会一并迁移浏览器记录。目前没有云端账号或统一同步。
- **进度丢了 / 想重置？** 先确认是哪一类记录。数据库与浏览器练习记录互相独立，目前没有统一重置入口；删除数据库会丢失其中的成绩与笔记，也不会同时清空浏览器里的练习记录。

本 README 只面向**使用者**。项目的架构、数据模型、完整 API、目录结构等开发者资料，
维护在另外两个文件里（它们才是权威基线，且随版本持续更新）：

## 当前互动课程

L2–L6 已接入逐步推理、按需标准讲解和独立毕业任务，当前含 47 课、200 个互动步骤（另含 L7 样板）；历史讲义与笔记入口保留。部分关键误区支持课中补救与至少 24 小时后的新情境验证，记录保存在当前浏览器。

毕业任务可下载数据、代码骨架和验收工具，需在本地 Spark 环境运行。L2/L3 的查询与 Parquet 交付分开，只查询通过为 PARTIAL；当前 Windows 开发机的 Parquet 完整写出仍待补验。L4–L6 分别交付实际计划、分区证据、连接结果与诊断草稿，参考实现的自动检查已实跑通过；诊断论证仍需人工核对，也不提供生产性能认证。
