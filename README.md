# Spark Quest

**一个受 Duolingo 启发的 Apache Spark 互动学习应用。**

从一小份数据出发，先预测结果、动手作答，再读反馈与讲解。把 RDD、DataFrame、SQL、执行计划、Shuffle、JOIN 和性能调优拆成连续的小步，让学习过程始终有问题可想、有结果可验证。

面向希望系统入门或重新梳理 Spark 的学习者。建议具备基本的 Python 阅读能力；SQL 会在课程中逐步引入。应用为本地运行、单用户模式，无需注册账号。

> 当前课程快照：**8 个阶段 · 68 课 · 315 个互动步骤 · 680 道当前测验/复习材料**。以下说明对应 2026-11-10 的实现；历史演进见 [CHANGELOG](CHANGELOG.md)。

## 怎样学习

1. **沿课程地图前进**：从 L0 建立直觉，再逐步进入编程、执行机制和调优。
2. **在题目中理解概念**：用具体数据预测输出、补全答案或选择方案；作答后查看解释、边界与常见误区。
3. **按需补课**：打开当前步骤的标准讲解；历史原文和个人笔记也保留。长文阅读时可随时收起或一键返回当前练习。
4. **检验与回访**：完成课末测验，再按计划复习。部分关键误区另有课中补救和至少 24 小时后的新材料验证。
5. **在电脑上实际运行**：L0 提供第一个 CSV 程序，L1–L7 各有独立毕业任务，可下载数据、代码骨架、验收器和参考实现。

日常可以从首页的推荐课、到期复习或薄弱题开始。课程地图展示学习进度，连续学习记录和成就系统提供阶段目标。

## 课程路线

| 阶段 | 主题 | 课数 | 主要练习方向 |
| --- | --- | ---: | --- |
| L0 | Spark 初识与第一个程序 | 5 | 计算与存储、Driver/Executor、SparkSession、CSV 小程序 |
| L1 | RDD 基础 | 6 | 分份计算、转换与行动、词频统计、走向 DataFrame |
| L2 | DataFrame 核心 | 10 | 检视、筛选、列加工、去重、聚合与数据交付 |
| L3 | Spark SQL | 10 | 查询、NULL、分组、窗口、连接与函数 |
| L4 | 执行计划 | 9 | 逻辑与物理计划、执行边界、根据计划解释计算 |
| L5 | 分区与 Shuffle | 9 | 数据分布、宽窄依赖、分区调整与搬运成本 |
| L6 | JOIN 与 Broadcast | 9 | 连接语义、重复键、连接策略与广播边界 |
| L7 | 性能调优 | 10 | 缓存生命周期、内存共享与回收、倾斜、AQE 与证据诊断 |

全部课程已有互动步骤与标准讲解；当前另有 **64 组课中补救与隔天验证目标**。毕业任务要求运行程序、检查结果并解释证据，网页不会代替你执行 Spark。

完成课程的目标是：能编写和解释基础 Spark 数据处理，读懂常见执行计划，并用结果与计划判断分区、连接、缓存等选择是否合理。课末分数与小数据验收不能替代真实项目经验或生产调优能力。

## 本地运行

运行学习应用需要 Python、Node.js 和 npm。**只有运行下载的 Spark 实作时，才另外需要兼容的 PySpark 与 Java 环境**，具体要求见各任务包的 `README.txt`。

下面命令以 Windows PowerShell 为例，从本仓库根目录执行。

### 首次安装

后端：

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

另开一个终端安装前端依赖：

```powershell
cd frontend
npm install
```

### 启动与关闭

终端一，启动后端：

```powershell
cd backend
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 9000 --reload
```

终端二，启动前端：

```powershell
cd frontend
npm run dev
```

打开 **http://localhost:6001**。后端首次启动会自动创建 SQLite 数据库并安装课程与题库；接口健康检查地址为 `http://127.0.0.1:9000/api/health`。

停止时在两个终端分别按 `Ctrl+C`。前端配置端口为 **6001**，API 代理指向后端 **9000**；若端口被占用，先检查终端提示。不要使用浏览器会阻止的旧端口 6000。

现有本机工作区还在仓库的上一级提供 `启动spark_duolinguo.bat` 与 `关闭spark_duolinguo.bat`，可双击管理前后端。关闭脚本支持 `--check` 只检查、`--no-pause` 关闭后直接退出；这些脚本位于仓库外，单独克隆本仓库不会包含它们。

macOS/Linux 可使用同样的前后端命令，将虚拟环境 Python 路径替换为 `./.venv/bin/python`。

## 手机访问与 iOS 主屏幕

电脑与手机处于同一局域网时，先在电脑启动前后端，再在手机打开 `http://电脑的局域网IP:6001`。前端开发服务器监听局域网，API 请求由它转发到电脑上的后端；电脑需要保持运行，并允许防火墙放行前端端口。

已提供 Web App Manifest、SVG 图标、PNG 安装图标、iOS 主屏幕图标与安全区适配。在 iPhone Safari 中通过“分享 → 添加到主屏幕”使用独立窗口入口。

**当前 PWA 不支持离线学习或离线提交。** Service Worker 只在生产构建注册，提供断网提示页与少量图标缓存，不缓存 API。完整的生产安装体验应在 HTTPS 下验证；局域网开发访问用于调试。

生产部署需将 `frontend/dist` 作为静态站点，配置单页路由回退，并将同源 `/api` 转发到后端。Vite 的开发代理不随构建产物发布；当前没有登录鉴权，部署应限定在自己的受控环境。

## 学习记录保存在哪里

| 位置 | 保存内容 | 迁移注意 |
| --- | --- | --- |
| `backend/spark_quest.db` | 正式成绩、掌握与解锁、间隔复习、作答历史、笔记、永久成就等 | 停止后端后备份数据库；不要将个人数据库提交到仓库 |
| 当前浏览器的本地存储 | 课中作答、补救、隔天验证、毕业任务草稿、本机成就等 | 复制数据库不会带走这些记录；清理站点数据会丢失它们 |

目前没有云端账号、跨设备同步或统一导入导出。手机访问同一后端时共享数据库记录，但浏览器练习记录各自独立。`localhost`、`127.0.0.1`、局域网 IP 或不同端口属于不同站点，本地练习记录不会自动互通。

升级代码前建议备份数据库并保留浏览器站点数据。不要通过删除数据库来处理普通启动问题；题库保留历史版本，因此数据库中的总题目行数可能多于当前使用的 680 道。

## 当前边界

- **学习质量仍在打磨**：全量互动覆盖已经完成，题库公平性、概念递进与真实学习效果仍需持续复核；保留的历史原文可能包含旧表述，学习以标准讲解及勘误为准。
- **实作需要独立环境**：网页不运行用户提交的 Spark 代码；验收器通过只表示对应检查通过，部分诊断文字仍需人工核对。
- **Windows 文件实作仍有已知限制**：当前开发机 L2/L3 毕业任务的 Parquet 写出受 `NativeIO$Windows.access0` 环境问题阻挡，只查询通过的 `PARTIAL` 不等于完整交付通过。
- **版本验证有范围**：部分讲解参照 Spark 3.5.x 文档，本机实跑使用 PySpark 4.2；不代表所有 Spark、Python、Java 组合或真实集群都已验证。

## 开发与维护

技术栈：React 18、TypeScript、Vite；FastAPI、SQLAlchemy、SQLite。

```text
frontend/
  src/components/       互动播放器、阅读与答题组件
  src/pages/            首页、地图、课程、测验、复习与成就页面
  src/content/          互动课程、标准讲解与验证材料
  public/practice/      可下载的实作任务包
  scripts/              内容编写、发布校验与浏览器检查
backend/
  app/                  API、课程种子、分用途题源与进度逻辑
  test_*.py             后端测试
```

前端常用检查，在 `frontend` 执行：

```powershell
npm run build
npm run check:css
npm run test:journey
```

`build` 会先运行内容守卫，再做 TypeScript 检查和构建。前端测试需要支持相关 Node 测试脚本的运行环境；浏览器检查另需 Playwright 和正在运行的本地预览。

后端题库与学习规则测试，在 `backend` 执行：

```powershell
.\.venv\Scripts\python.exe -m unittest test_l0_bank test_question_polish test_l1_l7_bank test_l3_l6_bank test_l2_bank test_extension_lessons test_learning_achievements
```

前端 CSS 使用全局作用域，新增类名必须遵守组件/页面前缀约定，避免跨页覆盖。修改前阅读[样式维护约定](frontend/src/pages/README.md)。课程与下载资产也有版本及摘要校验，请使用对应作者脚本和发布流程，避免直接修改生成结果造成漂移。
